# Aini Aden Portfolio

A responsive HTML/CSS/JavaScript portfolio in the “People, Patterns & Possibilities” editorial style.

## Open in VS Code

1. Unzip the project.
2. Open the `aini-portfolio` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Files

- `index.html` — portfolio homepage and project carousel
- `styles.css` — shared portfolio styling
- `script.js` — carousel interaction
- `sst-workflow.html` — interactive SST workflow case-study page
- `assets/` — add your screenshots, photographs and mockups here

## Before publishing

- Replace `hello@example.com` with your real email address.
- Replace placeholder project links as case studies are completed.
- Add compressed portfolio images to `assets/`.
- Update the Back to Case Study link in `sst-workflow.html` if your final URL changes.
