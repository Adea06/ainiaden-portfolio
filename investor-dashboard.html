The project

As part of my MSc Data Science at the University of Leicester, I worked on a live research brief from Lambda BI Ltd, sourced through Uniworx, which connects students with real briefs from industry partners.

Working in a group of four, we investigated whether behavioural finance indicators could improve financial prediction beyond what technical indicators alone can offer. I independently built the LightGBM classification model, the explainability analysis and the Streamlit dashboard, then redesigned the dashboard around the needs of an investor.

That redesign centred on one question: how can an investor compare a technical baseline with behavioural signals while staying critical of the model, rather than blindly trusting it?

01 Discover

From model outputs to investor questions.

Starting point · Review of my original dashboard

The first dashboard translated the model out of notebooks, but it was still shaped around the analysis rather than the investor. It was multi-page, scroll-heavy and made users work to answer four basic questions:

  • Did behavioural information actually improve the prediction?
  • How confident was the model?
  • What evidence shaped the result?
  • Would the model transfer to another market?

These were design hypotheses from reviewing the interface and model evidence. Investor interviews and usability testing are still needed to validate them.

Key design decisions
Comparison

Compare technical only with technical + behavioural

Separate pages made comparison harder. Side-by-side results expose changes in direction and probability.

Uncertainty

Keep probability beside direction

A directional label is quick to scan. Probability provides context so it is less likely to be read as a certainty.

Progressive disclosure

Let investors inspect the evidence

The overview answers the immediate question; the Behavioural impact tab and explanations support deeper review.

Feasibility

Make data limits explicit

Technical + behavioural depends on a timestamped news pipeline. The interface must distinguish historical evidence from live predictions.

Final dashboard

The redesigned overview puts the signal first: choose a market and date, review the direction and probability, then inspect the supporting evidence. The Behavioural impact tab provides a separate route into comparison.

Model output → uncertainty → interface. I used probabilities and explainability evidence to avoid presenting a prediction as certainty.

Real-world constraint

The original dashboard did not have a validated live-news pipeline. I therefore avoided presenting Technical + behavioural as a fully live prediction. Price and technical context can support current views, but new behavioural predictions require the same timestamped news → sentiment pipeline used during training.

Richer behavioural model↔Reliable live dataClarity and reliability over feature completeness.

Optional research detail

Behind the classification model

The wider research explored both return prediction and market direction. My contribution focused on LightGBM classification and how its uncertain outputs should be communicated.

01 / Data pipeline

  1. InputsHistorical market prices, technical indicators, VIX and financial news.
  2. PrepareAlign timestamps, score news with FinBERT, and construct lagged and rolling features.
  3. CompareTrain a technical-only baseline and a technical + behavioural LightGBM model using time-based evaluation.
  4. Explain and presentEvaluate predictions, inspect SHAP contributions and present the signal with probability and context in Streamlit.

02 / Why focus on classification?

Regression in the wider research produced weak estimates of return magnitude, with negative or near-zero R². That did not support presenting an exact return estimate as a dependable answer.

The dashboard therefore focuses on direction and probability. Adding behavioural indicators to the technical baseline allowed us to test whether they improved directional classification. This is a change in the question being answered, not a guarantee of accurate prediction.

Return magnitude → Direction + probability → Supporting evidence

03 / What changed with behavioural indicators?

Held-out classification results · Technical only → Technical + behavioural
MarketF1RecallROC-AUC
S&P 5000.589 → 0.6250.565 → 0.6480.396 → 0.389
FTSE 1000.268 → 0.4330.171 → 0.3240.528 → 0.481

F1 and recall improved, but ROC-AUC did not. Behavioural indicators helped some classification outcomes without establishing reliable separation of the classes. This distinction is why the interface keeps uncertainty visible.

The S&P-trained model reached 0.694 F1 in the project’s Russell 2000 external evaluation. Transfer still requires validation for each market and period.
